# Database Package Guidelines

These instructions apply to `internal/db/` and override general editing guidance where generated files are involved.

## Generated and Handwritten Files

- `pool.go` is handwritten and may be edited normally.
- `db.go`, `models.go`, and `*sql.go` are generated by sqlc. Never edit them directly.
- Make schema changes in `sql/migrations/` and query changes in `sql/queries/`, then run `sqlc generate` from the repository root.
- Generated diffs should be explainable entirely by the corresponding SQL source change.

When database behavior must be customized beyond generated queries, prefer a clearly handwritten file in this package rather than modifying generated output.
